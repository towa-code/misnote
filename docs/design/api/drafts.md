# API：下書き（drafts）

ベースURL: `https://api.misnote.com/v1` / 認証・エラー: [共通仕様](./conventions.md)

クイック保存で書き留めた「まだ問題になっていないメモ」を扱う。`questions` / `mistake_notes` とは独立したリソースで、本文（`body`）しか持たない。編集はせず、本登録するか削除するかのどちらか。

## エンドポイント一覧

| メソッド | パス | 説明 |
|---------|------|------|
| GET | `/drafts` | 下書き一覧取得（新しい順） |
| GET | `/drafts/{id}` | 下書き取得 |
| POST | `/drafts` | 下書き作成 |
| DELETE | `/drafts/{id}` | 下書き削除 |

---

## 下書き一覧取得
`GET /drafts`

`created_at` の降順（新しい順）で返す。

**クエリパラメータ**

| 名前 | 既定値 | 説明 |
|------|--------|------|
| `limit` | 100 | 取得件数（1〜500） |
| `offset` | 0 | 取得開始位置 |

**レスポンス**
```json
[
  {
    "id": "uuid",
    "body": "模試 大問2(3) 濃度の計算で単位を揃え忘れた",
    "created_at": "2026-08-09T17:52:00+09:00"
  }
]
```

---

## 下書き取得
`GET /drafts/{id}`

問題登録画面（`/register?draft={id}`）が本文を読み込むために使う。

**レスポンス**
```json
{
  "id": "uuid",
  "body": "模試 大問2(3) 濃度の計算で単位を揃え忘れた",
  "created_at": "2026-08-09T17:52:00+09:00"
}
```

- `404 Not Found`（存在しない、または他のユーザーの下書き）

---

## 下書き作成
`POST /drafts`

**リクエスト**
```json
{ "body": "模試 大問2(3) 濃度の計算で単位を揃え忘れた" }
```

`body` は1文字以上。空文字は `422`。

**レスポンス**
- `201 Created`

```json
{
  "id": "uuid",
  "body": "模試 大問2(3) 濃度の計算で単位を揃え忘れた",
  "created_at": "2026-08-09T17:52:00+09:00"
}
```

---

## 下書き削除
`DELETE /drafts/{id}`

本登録が成功したあと、フロントエンドがこのエンドポイントで下書きを片付ける。ユーザーが一覧から手動で消すときも同じ。

**レスポンス**
- `204 No Content`（成功時）
- `404 Not Found`（存在しない、または他のユーザーの下書き）
