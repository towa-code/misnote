# 画面：問題の編集

**目的：** 登録済みの問題の科目・単元・問題文・正解をあとから直す。科目・単元を変えれば別の場所へ移動でき、不要な問題は削除できる。克服済み⇄苦手中の切り替えもここで行う。

パス: `/questions/{question_id}/edit`（`?subject=<科目id>` 付きで来たら、戻り先をその科目で絞り込んだ一覧にする）

入口: [苦手問題一覧](./mistake-list.md) の各行の「編集」ボタン

---

## レイアウト

1カラム。上から「問題・正解」フォーム、操作ボタン、「状態」欄。

---

## 問題・正解

| 項目 | 内容 |
|------|------|
| 科目（必須） | 全科目のドロップダウン。変えると単元の選択は空に戻る |
| 単元（任意） | 選んでいる科目の単元。単元が無い科目では選べない |
| 問題文（必須） | テキストエリア |
| 正解（任意） | テキストエリア。空にして保存すると正解は消える |

間違えた理由・学び・タグ・復習日は間違いノート側の項目なので、ここでは扱わない（[復習](./review.md) で編集する）。

---

## 操作

| 操作 | 詳細 |
|------|------|
| 保存する | `PUT /questions/{id}` → 苦手問題一覧に戻る。未変更のあいだは押せない |
| キャンセル | 苦手問題一覧に戻る |
| この問題を削除 | 確認ダイアログ（「間違いノートと解答履歴も一緒に削除されます」）→ `DELETE /questions/{id}` → 苦手問題一覧に戻る |

---

## 状態

今の状態（「苦手中」か「克服済み」）と、切り替えボタンを1つ置く。押すとその場で反映し、苦手問題一覧に戻る。

| 今の状態 | ボタン | 動作 |
|------|------|------|
| 苦手中 | もう完璧！ | mastered にする（復習日は消える） |
| 克服済み | やっぱり苦手 | active に戻す（連続正解は0に戻る） |

フォームに未保存の変更があるあいだは押せない（「先に変更を保存してください」）。間違いノートが無い問題では、この欄は出ない。

---

## エラー

- 問題が見つからない（404）：「問題が見つかりません。」＋一覧へ戻るリンク
- 保存・削除・状態変更の失敗：フォームの下にメッセージ。入力内容は残す

---

## 使用API

- `GET /questions/{id}`
- `GET /subjects`
- `GET /subjects/{id}/units`
- `GET /mistake-notes/{id}`（状態欄）
- `PUT /questions/{id}`
- `DELETE /questions/{id}`
- `PUT /mistake-notes/{id}/status`
