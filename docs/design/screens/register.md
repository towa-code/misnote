# 画面：問題登録

**目的：** 問題文・正解・間違えた理由・次の復習日を一画面で登録する。

---

## レイアウト

2カラム（左：問題・正解 / 右：メモ・復習日）

768px 未満では1カラムに積む（[共通UI仕様](./common-ui.md) 参照）。

---

## 入力項目

| 項目 | 入力形式 | 必須 |
|------|---------|------|
| 科目 | セレクトボックス | ✓ |
| 単元 | セレクトボックス（科目選択後に動的表示） | - |
| 問題文 | テキストエリア | ✓ |
| 正解 | テキストエリア | - |
| 間違いの種類 | タグ選択チップ（6種から1つ・もう一度押すと解除） | - |
| 間違えた理由 | テキストエリア | ✓ |
| 今回学んだこと | テキストエリア | - |
| 次の復習日 | 日付ピッカー ＋「+1日 / +3日 / +7日」クイックチップ（今日基準・フロントのみ） | - |

---

> 「正解」と「間違えた理由」の必須が当初設計から入れ替わっている。記述式など正解が一意に定まらない問題があるため正解を任意にし、代わりに「なぜ間違えたか」を必ず書かせる方針に変えた（コミット d9d14c4）。

---

## 下書きからの本登録（`/register?draft={id}`）

[クイック保存](./quick-save.md)の下書き一覧で「登録する」を押すと、`?draft={id}` 付きでこの画面に来る。

- `GET /drafts/{id}` で本文を取得し、**問題文**に流し込む。他の項目は空のまま
- 下書きが取得できなかった場合（すでに削除済みなど）は何も流し込まず、通常の登録画面として動作する
- 登録に成功したら `DELETE /drafts/{id}` で下書きを片付けてからホームに戻る
- 下書きの削除に失敗しても登録自体は成功しているので、エラーにせずホームに進む（下書きが一覧に残るだけ）

---

## 操作

- 登録ボタン → 問題を保存してホームに戻る
  - メモまたは復習日が入力された場合、`mistake_notes` も自動作成（API側で処理）

---

## 使用API

- `GET /subjects`
- `GET /subjects/{subject_id}/units`
- `POST /questions`（`memo`・`learning`・`next_review_at`・`reason_tag` を同時送信）
- `GET /drafts/{id}`・`DELETE /drafts/{id}`（`?draft={id}` 付きで来たときのみ）
