# 画面遷移図

```
                    ┌─────────────────────────────────────────┐
                    │          左サイドバーナビゲーション          │
                    │  ホーム ／ クイック保存 ／ 苦手問題一覧      │
                    │  ／ 科目・単元管理                          │
                    └─────────────────────────────────────────┘

ホーム
（今日の復習一覧＋復習日未設定）
    │
    ├─ 問題をタップ ──→ 復習
    │                    │
    │                    ├─ 正解 ──→ 次の復習日を設定 ──→ ホームに戻る
    │                    │            ├─ 3連続正解なら「もう完璧かも？」と提案
    │                    │            └─ もう完璧！（克服済みにする） ──→ ホームに戻る
    │                    │
    │                    └─ 不正解 ──→ メモ・復習日を編集 ──→ ホームに戻る
    │
    └─ 「＋」ボタン ──→ 問題登録 ──→ ホームに戻る

クイック保存
    │
    ├─ 「書き留める」ボタン ──→ 保存モーダル（閉じずに連続保存）
    │
    └─ 「登録する」ボタン ──→ 問題登録（問題文をprefill）
                                └─ 登録成功 ──→ 下書きを削除 ──→ ホームに戻る

苦手問題一覧（苦手中／克服済みのタブ、科目で絞り込み可）
    │
    ├─ 「復習する」ボタン（苦手中のみ） ──→ 復習（同上）
    │
    └─ 「編集」ボタン ──→ 問題の編集
                          ├─ 保存 ／ 削除 ──→ 苦手問題一覧に戻る
                          └─ もう完璧！ ／ やっぱり苦手 ──→ 苦手問題一覧に戻る

科目・単元管理
    │
    └─ 削除が 409（問題が残っている） ──→ 「この科目の問題を見る」 ──→ 苦手問題一覧（その科目で絞り込み）
```
