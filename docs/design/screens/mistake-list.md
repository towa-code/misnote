# 画面：苦手問題一覧

**目的：** active な mistake_notes を一覧表示する。克服済み一覧はタブで切り替え。

---

## タブ構成

- **「苦手中」タブ**（active）
- **「克服済み」タブ**（mastered）

両タブとも、一覧の上に**間違いの種類による絞り込みチップ**を出す。

- チップは「すべて」＋そのタブに実在するタグ＋「未分類」（`reason_tag` が `null`）で、それぞれ件数を添える
- 件数は表示中の一覧を数えているだけで、集計APIは使わない。0件のタグは出さない
- タグが1つも付いていないうち（＝「すべて」と「未分類」しか並ばないとき）はチップ自体を表示しない
- 選択中のチップをもう一度押すと解除。タブを切り替えたときも絞り込みは解除する（タブごとに付いているタグが違うため）
- 絞り込みの結果が0件のときは「この種類の問題はありません。」と表示する

---

## 苦手中タブ

### 表示データ

- 問題文（先頭50文字程度）
- 科目名 / 単元名
- 間違いの種類（`reason_tag` があるときのみバッジ表示）
- 間違えた回数 / 連続正解回数（例：「連続正解 2回」）
- 次の復習日

### 操作

- 「復習する」ボタン → [復習](./review.md) へ
- 「克服済みにする」ボタン → その場で mastered に変更

### 空状態

「苦手問題はありません」＋問題登録への導線

---

## 克服済みタブ

### 表示データ

- 問題文
- 科目名 / 単元名
- 間違いの種類（`reason_tag` があるときのみバッジ表示）
- 間違えた回数

### 操作

- 「苦手に戻す」ボタン → active に戻す（復習日は未設定に戻るため、ホームの「復習日未設定」から再設定する）

### 空状態

「克服済みの問題はまだありません。復習を続けよう」

---

## 使用API

- `GET /mistake-notes`（苦手中タブ）
- `GET /mistake-notes/mastered`（克服済みタブ）
- `PUT /mistake-notes/{id}/status`（克服済みにする / 苦手に戻す）
