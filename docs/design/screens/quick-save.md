# 画面：クイック保存

**目的：** 間違えた問題を、科目も理由も選ばずに**問題文だけ**で書き留められるようにする。授業中や模試の直後に手を止めずに記録し、落ち着いてから本登録する。

パス: `/quick`

---

## レイアウト

1カラム。ヘッダー（タイトル＋「書き留める」ボタン）＋下書き一覧。

保存操作はページ内では行わず、**モーダル**で行う。

---

## 下書き一覧

`GET /drafts` の結果を新しい順に並べる。各行の内容:

| 要素 | 内容 |
|------|------|
| 本文 | 改行をそのまま表示する（`whitespace-pre-wrap`） |
| 保存日時 | 例「8月9日 17:52」 |
| 「登録する」 | `/register?draft={id}` へ遷移し、本文を問題文に流し込む |
| 削除 | 確認ダイアログのうえ `DELETE /drafts/{id}` |

下書きが0件のときは空状態を表示し、そこからもモーダルを開ける。

---

## 保存モーダル

アプリ内で唯一のモーダル。ネイティブの `<dialog>` 要素と `showModal()` を使う。Escape での閉じる・フォーカストラップ・背景の inert 化・バックドロップをブラウザが担保するため、自前実装より事故が少ない。

- 中身はテキストエリアと「保存」ボタンのみ
- **保存してもモーダルは閉じない。** 入力欄をクリアし「保存しました（n件）」を表示して、背後の一覧を更新する。授業中に何問も連続で打ち込むのがこの機能の使い所なので、1問ごとに開き直させない
- 閉じるのは明示的に閉じたときだけ（閉じるボタン・Escape・バックドロップのクリック）
- 空のままでは保存できない（ボタンを無効化）

> 実装メモ：Tailwind の preflight が全要素に `margin: 0` を当てるため、`<dialog>` 既定の `margin: auto` による中央寄せが潰れる。`m-auto` を明示すること。

---

## ナビゲーション

`NAV_ITEMS` に含める。入口の軽さが目的の機能なので、モバイルのボトムナビから1タップで届くことに意味がある。

> ボトムナビは全項目を等幅（`flex-1`）で並べる。5項目になったので、375px 幅の端末で1セル 75px。ラベル「クイック保存」は 11px で実測 68px でぎりぎり収まるが、320px 幅（1セル 64px）では折り返す。

---

## 使用API

- `GET /drafts`
- `POST /drafts`
- `DELETE /drafts/{id}`
