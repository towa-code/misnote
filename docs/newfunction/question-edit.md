# 機能案：問題の編集画面

> ⚠️ **エージェントへ：** この機能は構想段階です。ユーザーが明示的に実装を指示するまで実装しないでください。

**目的：** 一度登録した問題の問題文・正解・科目・単元をあとから直せるようにする。

---

## 見つかった経緯

2026-08-09 のクイック保存の設計検討中に、**登録済みの問題にあとから正解を書き足す手段がアプリ上に存在しない**ことが分かった。クイック保存が作った穴ではなく元からある穴なので、その機能には含めず切り出した。

- `PUT /v1/questions/{id}`（`subject_id` / `unit_id` / `question_text` / `correct_answer` を全置換）は**すでに実装されている**。足りていないのは画面だけ
- 記述式などで正解を空のまま登録できる（`correct_answer` は任意）ため、「あとで正解を書く」は自然に起きる

---

## 概要（UX）

- 苦手問題一覧・復習画面から「問題を編集」に入れるようにする
- 編集できるのは questions 側の4項目（科目・単元・問題文・正解）。間違えた理由・学び・タグ・復習日は間違いノート側なので、既存の復習画面の編集で扱う
- 単元は科目に属するので、科目を変えたら単元をリセットする（登録画面と同じ挙動）

---

## API/DB 変更点

| 種別 | 変更 |
|------|------|
| API | なし（`PUT /v1/questions/{id}` をそのまま使う） |
| DB | なし |
| フロント | 編集画面（登録フォームの左カラム相当）と、そこへの導線 |

---

## 検討事項

- 登録フォーム（`register-form.tsx`、338行）を編集モードで再利用するか、別コンポーネントにするか。再利用するとモード分岐が増えるので、questions 側4項目だけの小さいフォームを別に作るほうが素直かもしれない
- 「編集」と「間違いノートの編集」が別画面なのはユーザーから見て分かりにくい可能性がある。1画面にまとめる案も検討の余地あり
